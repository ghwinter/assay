方法清单 M0–M9

每条方法给出：目的、步骤、产出形态、失败特征、根源（由根层哪个生成学科 导出，见 root.html §5）。顺序为建议执行序，M0 恒先。

M0 基底规则（恒先）

目的：使一切陈述可审计。
步骤：对每句断言标注其类别（定义 / 命题 / 证据 / 声明）；证据指定其形式 （测试、测量、审计）；声明指定其承认程序。
产出：标注过的陈述集。
失败特征：出现未标注的断言，或声明被当作证据使用。
根源：G1（声明地位的结构必然性见 root.html 命题 1.3）。

M1 推广（Generalize）

目的：从单例得到同类集合。
步骤：收集同一现象的不小于三个独立实例；列举它们的表面差异；提出共同形态假设； 验证假设在该类每个实例上成立；命名。
产出：一个有名字的形态 + 不少于三个实例 + 共同形态的陈述（附失效域或 "边界未查"声明）。
失败特征：以两个实例推广（样本不足）；把表面相似当共同形态（未验证）； 推广未附失效域。
根源：G5（实例收集是溯因的前置纪律）+ A.2。

M2 统一（Unify）

目的：把不同名字的相似形态化为一个形态。
步骤：取两个形态；尝试用同一语言陈述两者；若其中一者无法翻译为另一者的语汇， 则统一未成立；写出翻译表（旧名 → 新名 → 语义差异）。
产出：统一形态 + 翻译表。
判定标准：统一成立当且仅当两者可互译且互译不丢失语义。否则保留双形态并说明边界。
失败特征：命名上的合并（同一名字装两种语义）；强行翻译造成语义丢失； 虚假综合（用更大的上层标签覆盖未裁决的对立——与命名合并机制不同： 后者是两语义共用一名，前者是绕过张力直接升维）。
根源：G1（翻译表即显式态射）。

M3 普遍性追问（Universality）

目的：确定形态的成立边界。
步骤：对统一形态作三类检验——(1) 反例搜索（构造不满足形态的对象）； (2) 退化情形（边界参数，如零容量、空集、单元素）；(3) 邻居域试探（形态可否 平移到相邻领域）。
产出：形态的成立域 + 边界清单（含反例）。
失败特征：把"在样本上成立"当作"处处成立"；未检查退化情形。
根源：A（普适不可证实，只能做边界清单）。

M4 公理化（Axiomatize）

目的：把形态沉淀为最小基底 + 导出闭包。
步骤：(1) 列出所有声称；(2) 找出可作为公理的少量陈述（其余由它们导出）； (3) 验证极小基律：删去任一公理后，至少一项声称不可导出，否则该公理冗余； (4) 写出导出路径（每个非公理声称到公理的推导骨架）。
产出：公理集（极小）+ 导出闭包 + 推导骨架。
失败特征：冗余公理（极小基律违反）；把可导出项冒充公设；把不可判定项硬塞进 可证明区（伪精确）。
根源：G1 + G2（极小基律是类型系统的冗余消除）。

M5 元问题（Meta-question）

目的：对已形式化的系统再问"它立于什么之上"。
步骤：(1) 问：三分区（规则、证明、基底）由谁决定、立在什么上； (2) 对答案重复提问，上溯一层；(3) 上溯的终止条件：到达不可证明的基底 （其真值不由系统内部判定），此时把基底展出为假定（命名、陈述、标注"假定"）， 并指定承认程序（谁、按何种程序接受该假定）。
产出：分层结构（每一层的基底即上一层的对象）+ 展出过的基底清单 + 承认程序。
失败特征：无限上溯不停（不承认基底——回避终止条件）；把基底静默使用（未展出）。
根源：G2。

M6 结构-组合分析

目的：把系统分解为构件与组合法则。
步骤：(1) 列举构件；(2) 陈述组合法则；(3) 检验组合封闭性（构件经法则组合后 仍是构件）；(4) 找出法则不可组合的对象（闭包交集：某对象可定义但不可由法则 到达）；(5) 对这些对象明确处置（并入、拒绝、声明边界）。
产出：构件清单 + 组合法则 + 封闭性检验结果 + 不可组合边界。
失败特征：把不可组合对象静默排除；组合法则未检验封闭性。
根源：G4（封闭性检验即不变量）。

M7 弱涌现观测

目的：区分可推导的全局性质与不可推导的全局性质（弱涌现），并正确处置后者。
步骤：(1) 尝试从局部规则推导全局性质；(2) 推导失败时，判断是不可判（无算法） 还是可判但推导困难；(3) 不可判者：把该性质作为界值与监测对象展出（不假装可 推导）；(4) 可判但困难者：给算法或放弃并声明。
产出：全局性质清单，每项标注（可推导 / 不可判-展出 / 可判-未实现-声明）。
失败特征：把不可判性质当定理；把"推导不出"说成"推导不存在"而不给出依据。
根源：G6。

M8 信息论视角

目的：以守恒、容量、熵三问检查系统陈述的一致性。
步骤：(1) 守恒：消息/值是否凭空产生或消失（应守恒）；(2) 容量：通道、缓冲的 容量与流速是否匹配（不匹配时出现背压，背压的处置策略须显式）；(3) 熵：观测 缺损是否被当作信息完备（缺损须列出）。
产出：守恒审计 + 容量/处置策略清单 + 观测缺损清单。
失败特征：值丢失而无回传（守恒违反）；背压处置未声明；把噪声当信号。
根源：G4（三问皆不变量问题）。

M9 自指分层

目的：让系统可审计自身，且不妨碍基底。
步骤：(1) 为系统配审计机制（账本、探针、测试门）；(2) 审计机制可检查系统可否 检查自身（反射）；(3) 记录分层：任何一层的"自我证明"不可能（哥德尔），由该层 的上级审计或承认程序接管。
产出：审计机制 + 分层引用图 + 顶层的承认程序。
失败特征：用系统的内部证明声称系统整体可靠（自证）；审计机制本身无审计 （无 M0）。
增补（双时间尺度）：快尺度逐步纠偏（作用于单次推理）与慢尺度离线全局 审计（作用于整体配置）分开设置，对象与频率不同；慢尺度审计的固定三 模式：系统性偏差（某类路径反复高惊奇度）、不可收缩环（轨迹周期性重复）、 算法升降级（约束密度驱动切换）。
根源：G2。
