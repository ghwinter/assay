根层：最小生成集

本文是手册的第〇层。其余各层（方法 M0–M9、APM 循环、迭代纪律、领域投影） 由本文的生成集导出；导出关系见 §5。重构原则：底层思维、逻辑、模式、关系、 结构独立于任何项目与领域——因此根层只陈述一次，各领域文档改判为根层的投影， 不再各自另立体系。

§0 本文的自我标注（M0 应用于自身）

本文包含：定义 6 条、命题 3 条（T1/T2/A，各附证据形态）、生成学科 9 条（G1–G6 由两条定理与不对称导出；G7–G9 由完备性探询收编，见 §6， 各条内注明来源与导出关系）、导出表一张、极小基自检一组。 极小基的检验是论证级而非机械级——此限制显式声明，不冒充已验证。

§1 原语：陈述的四类标签

定义 1.1（陈述）：出现在推理、写作与工程中的原子语句。

定义 1.2（标签）：每条陈述属于且仅属于——

标签语义真值
定义引入对象与语汇，求一致性不求真无（只有良构与不良构）
命题关于对象的主张有，待验证
证据可执行的验证行为及其结果（测试 / 测量 / 审计）可复现
声明不可验证而依承认程序被接受的陈述被承认，非被证明

命题 1.3：声明不是防欺诈条款的附属品，而是 T1 的结构必然（§2）—— 任何接受链要么进入另一系统的证明（回溯继续），要么终止于承认程序； 终止处的陈述即声明。验证塔必然有声明层。

推论：三分区（定义/命题/证据）缺一类。未标注声明被当作证据使用之所以 是根病理，不在于它常见，而在于它使发现机制本身失效——其余标签错误尚可 被审计清单捕获，此错误杀死审计的锚点。

§2 两条定理与一个不对称

命题 T1（自证不可能）：含算术、一致、且可表示自身语法的系统不能在 内部证明自身一致（Gödel II）；真在该系统内不可定义（Tarski）；行为的 任何非平凡语义性质不可判定（Rice）。三者非三个孤立事实，是同一机制的 实例：对角线化的不动点（Lawvere 不动点定理给出统一形态）。

证据：公知数学定理。

推论 T1.1（验证塔）：对任一系统 S 的验证发生在 S 之外。塔的每层把 下一层的对象当作自己的数据；塔不终止于证明，终止于承认程序。

推论 T1.2（层间接口）：跨层引用必须显式，接口只有三种形态—— 翻译表（M2）、承认程序（M5）、修正程序（语义变更的法定通道）。 静默跨层引用是根病理的第二个实例。

命题 T2（检验不分解 / 整体论）：当预测 P 由合取 H∧A₁∧…∧Aₙ 导出时， P 的反例只否定整个合取；使合取失效的指派不唯一，且在既有证据内不可裁决。 逻辑骨架平凡（否定后件否定的是合取）；裁决不可性是本命题的实质。

证据：逻辑论证 + 手册外的历史实例（口径分裂、铺贴性失效均属"检验 通过了 H 而坏在某个未被点名的 Aᵢ"）。

推论 T2.1：错误定位的唯一资源是独立通道。单路径验证的通过不构成 定位——它至多证明合取整体在某次检验下存活。

推论 T2.2（独立性的操作定义与限度）：两通道独立 = 两者不共享任何 未验证组件。此定义的满足不可自证（检查独立性的代码本身是组件）—— 故独立性按清单登记为声明：逐项列出两通道在哪些组件上分离。

命题 A（反驳/证实不对称）：全称命题的反驳具有限见证（一个反例即 完成）；证实没有有限见证。

证据：一阶语义平凡事实。

推论 A.1（目标反转）：方法论的目标函数不是"保证正确"，是"最大化 错误发现率、阻断错误传播"。负知识便宜、可靠、有限步；正知识昂贵、 开放、一般不可得。整部手册的工程取向由此一句定下。

推论 A.2：普适性断言必须自附失效域——不能证实普适，只能划定已反驳 与未反驳的边界。

§3 生成学科（G1–G9）

九条机械学科，各注明由何导出（或由完备性探询收编）。每条含：内容、 失败形态、机械检查。

G1 类型纪律【导出自：定义 1.2 + T2（不合类型的分歧无意义）】

内容：一切对象带类型。陈述带标签（§1）；数据带口径（量纲、定点刻度、 增量/位移）；比较带轴（布尔可判定 / 有序可判断 / 义务论强度 / 证据论 模态四轴不得互比）；语义映射带翻译表。算子仅在类型匹配处复合，转换是 显式态射。

失败形态：未标注陈述（根病理）；跨轴比较（伪验证的最常见来源）； 口径混用（同一对象两个读数被"选一个顺手的"）。

机械检查：标注覆盖率；口径归零检验（候选关系量纲不闭合即淘汰， 纯符号操作排除整类候选）；轴声明；借形检查——凡引入数学词汇 （熵、能、曲率、吸引子、测地线等），须同时登记三元组：承载对象是什么、 该量如何定义、由谁在何处可测，三者缺一即降级为隐喻并标注"隐喻"， 对应关系须标注强度（类比 / 同态 / 同构不得混称"精确对应"）；失真登记 ——每个口径 / 编码除翻译表外登记其残差清单（该编码不可表达或必然磨平的 对象类），禁止把编码产物当作对象的全部。

G2 分层与承认【导出自：T1】

内容：验证塔显式分层；每层列出其基底；不可证明的基底展出为声明并 指定承认程序（谁、按何种程序接受）；层内不可自证，由上一层或承认程序 接管。上溯的终止不是失败，是把基底从暗处移到明处的完成。

失败形态：自证（用系统内部证明声称系统整体可靠）；静默基底（未展出 即使用）；无限上溯（拒绝承认程序——回溯的病态终点）。

机械检查：基底清单；承认程序记录；自证扫描（"本系统可靠"类陈述的 证明位置在层内还是层外）。补两条：基底允许竞争登记（多个候选基底并存， 选定基底本身是一条声明，禁止默会选定）；层间接口除三种形态外还有第四种 ——跨层捷径（跨度大于一层的依赖边）：这类边不可由相邻层推导预期，须 单列清单逐条审计，它既是静默跨层引用的藏身处，也是意外的产地。

G3 独立冗余【导出自：T2.1/T2.2 + A.1】

内容：不存在更高权威，只存在第二通道。验证预算全部花在通道独立性上。 分歧是可判定的且是可靠的错误信号；一致不是证明——尤其当两通道共享 隐藏组件时（共因伪证：同一作者、同一库、同一数据加载层上的"复算" 只验证其上的部分）。

失败形态：单路径确认；共享组件的双路径被当作独立验证；把一致当证明。

机械检查：独立性清单（组件级分离声明，声明形态）；分歧登记； 分歧定位规则（§4）。独立性清单另含位置维度：同结构位置的第二复述不构成 第二通道——独立通道应来自不同结构位置（跨视角审阅的价值即在此）。

实例校准：日志级复算验证的是计算层，不验证数据层——数据层需要 独立的整体不变量（G4）。"局部全过、整体仍错"的结构原因即在此： 所有局部通道共享了坏掉的组件。

G4 整体不变量【导出自：T2（整体论的数据形态）+ A.1】

内容：局部一致性不蕴含整体一致性（预层语义：局部截面处处一致不保证 整体截面存在）。每条管道、每个推导链必须登记其胶合不变量——铺贴性、 守恒性、封闭性、对称性零检验——与局部校验并列作为验收项。障碍可计算时 直接测量它（缺口序列即度量障碍的上循环），不待议。

失败形态：以局部校验的通过推及整体；值凭空产生或消失而无回传； 输出在应变的对称下不变而不报警。

机械检查：恒等式对账（望远镜求和、日界封闭、包边界无缝）；闭环 毛利归零；对称零检验。

注：G3 与 G4 是互补的两个检测器——G3 检测"算错了"，G4 检测 "对象本身就错"。缺一即剩半套。

G5 溯因隔离【导出自：T2（溯因是唯一引入新辅助假设的推理步）】

内容：溯因（最佳解释猜想）是唯一产生新假设的推理步，因此也是盲区的 主产地——它向合取里塞入未被点名的 Aᵢ。规则：溯因产物携带猜想状态； 猜想不得承重（承重 = 被裁决引用或被下游命题依赖为前提）；承重前必须有 对照检验设计。状态沿支撑链传播：命题继承其全部支撑路径上最弱边的状态。

失败形态：溯因固化（未经检验的解释被写成机制结论）；MISS 后的 归因叙事充当结论。

机械检查：状态传播规则；承重边状态审计（承重边处于猜想状态即矛盾 条目）。溯因条目另带归因层级字段（行动者 / 制度 / 结构）——层级错配是 溯因固化的常见形态（把结构性后果归为行动者策略，或反之）；约束登记分 硬 / 软两列，软约束须附变迁史或至少一个反例期——把可变说成不可变是 G6 伪精确的镜像。

G6 性质分类与处置【导出自：T1（Rice）+ A（不可证实者只能展出）】

内容：全局性质按可处置性分三类，处置不可跨类：可推导 → 给出推导； 可判但难 → 给算法或声明放弃；不可判 → 展出为界值与监测对象，不假装 可推导。把性质从一类挪到另一类陈述即伪精确。

失败形态：把不可判性质当定理；把"推导不出"说成"推导不存在"而 不给依据；把"尚未实现"说成"原理上不可能"。

机械检查：性质分类标注；展出清单（不可判者必须有监测面）。分类有 第二轴：对象系统的复杂性（简单 / 巨 / 复杂巨）——处置表是两轴的乘积， 同一性质在不同复杂性的对象上可处置性不同；任何方法论主张必须声明其 对象类型域。另：分类行为本身改变可处置性（重新命名即重新处置），故 重分类记为事件，逐次登记。

G7 边界不分离【完备性探询收编】

内容：一切划分皆有泄漏。任何分类、隔离、过滤方案必须随附 "不分离清单"：已知的概念重叠区、区内的外部裁决锚点、区分粒度对场域的 依赖声明。重叠区内的落点不可由内部推理自证，须引锚点裁决；过滤式方案 （关键词、互斥类别）在重叠区做完全分离拓扑上不可能，必有盲区。推理 轨迹中反复绕同一论证环（不可收缩环）是盲区信号——处置是升到更高层域 绕行，不是原地再解释。

失败形态：互斥格子化（假装类别可分离，导致过滤方案必有漏网）； 原地解环（对循环论证反复重述）；无锚点裁决（重叠区内靠更多内部推理 自证落点）。

机械检查：泄漏清单存在性（每个分类方案必须答出"哪些对象落在 类别之间"）；环检测与升域记录。

导出关系：与 T2 同源（重叠类别即共享组件的划分形态），但作为独立 失败面单列——G1 管类型与翻译，不管分类系统自身的泄漏。

G8 承重与分诊【完备性探询收编】

内容：验证与维护预算按承重性分配，不均匀摊铺。登记受力点清单 （失效后传导最快、修复成本最高的节点）——自上而下（找传导最快节点） 与自下而上（找高频复发区，症状区是上游错位最早的投射）两条路径互为 校验，交汇处优先盯防；复发问题强制回溯上游节点，症状处禁止直接修复； 不可逆节点优先防守，可逆性不明默认按不可逆处理。

失败形态：均匀用力；症状处修复（对投射区反复修补而上游错位不动）； 把不可逆当可逆而延误防守。

机械检查：受力点清单存在且非空；每条复发缺陷有指名的上游节点条目， 否则该修复标记"未定位"；动作清单逐项标可逆性等级。

导出关系：G3 说验证预算花在通道独立性上，本条回答独立通道指向哪里 ——传播最远的节点，是 T2.1 + A.1 的分配形态。

G9 干预纪律【完备性探询收编】

内容：发现错误之后的行为也在管辖内。干预的分类不由意图决定，由承接 后的实际走向决定；维护动作与维护效果分开对账（"明明在维护却持续恶化" 是标准病灶）；矛盾分结构性（源于基底与搭建方式，长期接纳、缓慢转化， 禁止速解预期）与运行性（日常摩擦，短期调节），并按此分配资源；常量 维护力度下错位频率持续上升 = 条件漂移触发器（重估基底，不是更用力）； 检测器对其历史残差的报警率衰减 = 钝化信号（通道适应慢性错误而丧失 检测力）。

失败形态：以维护意图抵账维护效果；对结构性矛盾投入速解资源； 检测器钝化（对长期存在的残差不再报警）。

机械检查：干预-效果对账表；同力度趋势扫描；报警率衰减扫描（各 检测器周期性重放其历史残差，验证现行报警率未低于初值）。

导出关系：G1–G6 全部止于发现，本条管辖发现之后——根层因此从 "检测器阵列"补全为"检测器 + 分诊 + 运维"。

§4 分歧定位规则（G3 的操作细则）

两个独立通道产生分歧时，分歧的类型定位错误的层：

分歧类型定位处置
数值分歧：同口径同输入，不同读数计算 / 编码层逐算子倒推，先查守恒
口径分歧：不同口径对同一对象不同读数不是错误，是口径边界登记为口径事实；禁止择顺者从之
判定分歧：同数据同判据，不同裁决公式 / 统计 / 守卫层查方向符号、删失、NaN 通路
语义分歧：同一形态两套形式化互译失败模型面该换，或翻译表缺失触发重定义程序，不修数据

末行是元层级的两部码触发器：多重形式化之间的分歧，是三方（作者、 审者、结构）都看不见、但结构可见的盲区的最终检测器。没有对推理的 更高权威，只有对推理的第二套记法（G3 在元层级的实例）。
