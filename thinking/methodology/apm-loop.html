APM 循环（Abstract → Pattern → Meta-question）

APM 循环是 M1–M5 的组合使用程序：以一次循环为单元，把一个问题域加工为 可审计的构成（定义 + 公理 + 证据面），并以"元问题"决定是否进入下一层循环。

1. 阶段定义

阶段输入操作输出
A 抽象一个问题或单例列举同类实例（≥3）；命名共同形态（M1）形态 + 实例集
P 模式形态 + 实例集统一异名同形（M2）；检查成立边界与反例（M3）；检验结构-组合封闭性（M6）统一模式 + 边界清单
M 元问题统一模式公理化（M4）；再问"立于什么之上"（M5）；以信息论/涌现/自指三问复核（M7–M9）构成 C + 基底 + 承认程序

2. 收敛条件

循环收敛，当且仅当同时满足：

  1. 每个声称属于（定义 / 命题 / 证据）之一且证据可执行（M0）；
  2. 公理集满足极小基律，导出闭包完整（M4）；
  3. 基底被展出并指定承认程序（M5）；
  4. 无未标注的假定（静默假定计数为零）。

不满足时循环继续：返回 A 阶段收集更多实例，或返回 P 阶段修正模式。

3. 元问题的推进规则（树的汇聚与自指）

问题空间可视为树：叶子是具体问题，主干是多个具体问题的共同形态， 汇聚处是元问题。对任意汇聚点可再问"它立于什么之上"，得到上一层的汇聚点。 该过程满足三条规则：

  • 层间推进：第 n 层的问题空间对象，是第 n+1 层问题空间的问题；
  • 层内不可自证：任何一层的正确性不由该层内部判定（Gödel/Tarski）； 其裁判在上一层或承认程序；
  • 递归允许：元问题可以是某子树的子节点（Feferman 反射塔的实践形态）， 即"元问题是子节点"成立，但需显式标注层号与所引用的基底。

4. 产物模板（每一轮循环的强制产出）

每一轮循环输出一张记录表，字段固定：

字段内容要求
名称形态的规范名（带英文对照）
定义一句话定义（M0 定义为定义）
实例不少于三个，各一行
边界反例或退化情形清单
形式化符号陈述（尽可能）
证据测试 / 测量 / 审计 / 声明，指明类别（M8 守恒检查含入）
承认不可证明部分 + 承认程序（M5）
层号该轮在树中的层位置（M9）

5. 已知应用实例（本手册的验证样本）

应用使用的阶段产物
五概念封闭A→P→M（M1–M4, M6）五概念 + §8.3 封闭判据
第五轴（目的相容）P（M3 边界追问）退化态定义 + 机械化分界
系统间接缝P→M（M2 统一 + M5）契约型位 + 可判定性全景
图范式覆盖A→P（M1+M2）三类边语义 + 原生/边界判定
义务账本与遥测M（M9 + M7）账本探针 + 观测接口
动态税M（M7 不可消成本）族 A 不可消 + 测量证据

这些应用同时作为产物模板的格式校验样本：模板可覆盖全部案例说明其字段完备。
