## Decision

- **Question:** 在 Assay examples 中增加什么小型真实计算项目，以检验智能体协作和证据闭环？
- **Accepted choice:** 在 examples/parallel-histogram 实现无第三方依赖的 Rust 字节直方图。公开 API 接受非零 worker 数；空输入返回 256 个零计数；非空输入使用最多 min(workers, input length) 个 scoped worker，各自统计互不共享的局部 256 桶数组，主线程确定性归并。提供串行实现作为 参考 oracle。测试覆盖空输入、边界、各 worker 数与串行 oracle 等价、计数和等于输入长度。 提供可手动运行的 release benchmark 输出吞吐，不设机器无关的速度阈值，不宣称并行在小 输入或所有平台上更快。通过父仓库的 Assay manifest、Spec Ledger 和端到端示例脚本验证。
- **Alternatives:** 新增较大服务，覆盖网络、持久化和部署但同时引入大量外部变量, 新增依赖输入分块与结果归并的并行直方图模块，以串行参考实现作独立对照（本决策）, 只添加过程文档，不引入可运行项目

## Assumptions

- **Assumption:** 字节域固定为 0..=255，直方图总是恰有 256 个桶；输入切片在调用期间不可变。
  - **Invalidated when:** 产品需求要求任意范围分桶、流式输入或在线更新。
- **Assumption:** 第一版以标准库 scoped threads 和每线程局部计数作为足够的并行方案；不保证对所有输入规模都加速。
  - **Invalidated when:** 基准在声明的目标工作负载上显示显著瓶颈或共享内存方案不满足明确性能预算。
- **Assumption:** 单次测试与本机 benchmark 分别只证明测试用例和测量环境下的性质，不代表所有输入、架构或负载。
  - **Invalidated when:** 出现测试覆盖范围无法满足的高风险使用场景或正式性能预算。
