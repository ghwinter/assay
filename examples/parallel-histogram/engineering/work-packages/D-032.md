# D-032: Bounded streaming histogram

## Objective

Evolve the existing parallel histogram into a small file-processing system without adding another
example. Preserve the in-memory API while making input, bounded scheduling, worker ownership,
shutdown, failure handling, and evidence visible.

## Work slices

1. Define validated pipeline configuration and checked accounting.
2. Implement Reader-to-bounded-queue production, worker-local counting, draining close, join, and
   error propagation.
3. Expose the pipeline as a file CLI with machine-readable output.
4. Verify behavior with an independent byte-count oracle, backpressure/short-read/error tests, and
   CLI integration tests.
5. Model the abstract finite queue/worker close protocol in TLA+; do not treat model checking as an
   implementation-refinement proof.
6. Bind checks to Assay claims and run them in the end-to-end workflow and CI.

## Handoff contract

Each slice has an explicit file boundary and a checker. The work package is a planning artifact, not
evidence that independent agents or teams executed the slices. No performance target, cancellation,
retry, checkpointing, or persistence is introduced.
