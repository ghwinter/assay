# 规范名表（词表）——一物一名（D-022）

双源禁令（宪法增长律；手册 SG1 的"极小基律（双源禁令）"）在词汇层的落实：
同一语义在体系内只允许一个权威名。本表是唯一裁决处——新名先入表再使用，
退役名保留"→"指向，不得在新文本中使用。命名空间声明见 §2，承认程序见 §3。

## 2. 命名空间（收编手册的编号映射）

《推理方法论》手册（thinking/methodology/，冻结不转写）自带编号，与仓库系列撞名。
**手册原文一字不改**；在本仓库语境引用手册条目时用加前缀的读法：

| 手册原文 | 本仓库引用形式 | 仓库侧占用（互不相干） |
|---|---|---|
| M0–M9（方法） | HM0–HM9 | M-001..M-xxx（元认知库方法） |
| G1–G9（生成学科） | SG1–SG9 | G-001..G-003（目标账） |
| L0–L5（审计梯） | AT0–AT5 | L1/L2/L3（lint 层级，仓库保留字） |
| 命题 A（反驳/证实不对称） | 手册命题 A | A / A' / 非A（宪法硬声明分类） |
| T1 / T2 | 原样引用（仓库无 T 系列） | — |
| F1–F9 / U1–U3 | 尚未收编——引用前须先收编目录实体 | — |

## 3. 承认程序（四标签的仓库形态，暂行）

宪法"中间地带非法"的运行细则：**声明**（不可验证而依承认程序接受的陈述）由
操作者按账本流程承认——D 账 `status: accepted` 的 rationale 即承认记录，
`anchor: owner=human` 即承认签名。AI 产出一律"证据待验"：未经检查器运行或
操作者签名，不得被下游引用为结论（手册 discipline §4 的仓库化）。
本节为暂行形态，宪法四标签修订（D-020 合并第(3)步）时升入宪法后由本表回指。
